# -
本作品基于安路 PH1P35 FPGA 开发板，设计一套实时目标检测与二轴云台指向系统。系统通过 MIPI 摄像头采集 1080P 图像，在 FPGA 内部以纯 RTL 硬件流水线完成 ISP 图像处理、红点目标跟踪、运动检测与几何手势识别，通过 HDMI 实时输出画面，叠加标记框、目标坐标、手势数字与系统诊断状态。FPGA 输出 PWM 信号驱动双轴 MG996R 舵机云台，实现红点目标自动跟踪对准；手势识别无需神经网络，依靠距离变换与三层圆周采样实现 0‑5 手指计数。整套系统无处理器、无操作系统，端到端延迟固定 2 帧，充分展现 FPGA 在并行视觉处理、低延迟人机交互与硬件闭环伺服控制方面的优势。
